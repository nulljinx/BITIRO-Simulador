PROGRAMACIÓN / ARDUINO C++

Tu programa Ctrl + Enter para ejecutar

Escribe y ejecuta tu propio programa para controlar al IROH. Guarda el código localmente por pista. Usa lineaIzquierda(), lineaCentral() y lineaDerecha() para aplicar tu calibración. Interpretación didáctica de Arduino/C++.

Edita tu programa y ejecuta.
Funciones y límites de este editor

Movimiento: avanzar, retroceder, girarDerecha, girarIzquierda, detenerse, pausa. Sensores: leerSensorLineaIzquierdo/Central/Derecho() devuelve lectura bruta (0–1023). leerLineaNormalizada(0/1/2) devuelve 0–1000. lineaIzquierda/Central/Derecha() devuelve 1 si detecta negro según tu calibración. leerUmbralLinea() devuelve el umbral normalizado. También: IR izquierdo y derecho; sonar virtual de distancia. LCD: escribirPantalla y borrarPantalla. Golpe: moverServoGolpe(ángulo). Admite int, if/else, while, expresiones básicas y setup()/loop(). No es un compilador completo de Arduino ni utiliza la biblioteca original en el navegador.
