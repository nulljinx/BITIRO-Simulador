BITIRO SIMULADOR · INICIO RÁPIDO

En línea:
https://simulador.nulljinx.com

1. Elige S01–S08, Óvalo u Ocho.
2. Lee el objetivo de práctica de la pista.
3. Modifica el código del editor.
4. Pulsa Ejecutar.
5. Usa Pulsador e IR cuando tu programa los lea.
6. Observa sensores, sonar, motores, LCD y garra.
7. Pausa, reinicia, corrige el código y vuelve a probar.

IMPORTANTE
- Si tu código contiene botonInicio(), se detiene en esa llamada hasta presionar Pulsador.
- Si no contiene botonInicio(), comienza inmediatamente.
- La garra usa moverServoGolpe(-1), moverServoGolpe(0), moverServoGolpe(1).
- Más -> Editar escenario permite añadir/mover/eliminar cajas.
- La pista no corrige el código ni decide la ruta correcta.

Ejemplo:

void setup() {
  inicializarMovimiento();
  inicializarSensores();
  botonInicio();
}

void loop() {
  if (lineaCentral()) avanzar(30);
  else if (lineaIzquierda()) avanzar(10, 30);
  else if (lineaDerecha()) avanzar(30, 10);
  else detenerse();
}

Funciones propias con parámetros y return también están soportadas.
